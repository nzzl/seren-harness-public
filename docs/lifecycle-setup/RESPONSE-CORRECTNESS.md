# Response correctness

The checker compares the complete observed reply with the expected marker-bound response.
Persisted evidence contains a sha256 of the retained (sanitized, capped) text.
The current and corrected skills are demonstration prompt artifacts, not a record of any employee.
Instruction changes require preview, identity checks, explicit approval, read-back and restoration.
See ../OPERATOR.md.

The guarded command is `python -m seren_harness instruction-update`; configure the recipient package before execution.
